# Melbourne City Property Sales: From Data to Dashboard
### A Unique Data-Driven Property Investment Guide

> Turning Melbourne property data into investment insights - My latest creation at Innomatics Research Labs, Dilsukhnagar

---

### 📌 Project Overview
The Melbourne property market is not just about houses. It's about location, lifestyle, and crores of investment decisions. This project analyzes Melbourne City property sales data to decode market trends, suburb performance, seller strategies, and property features.

This is a **UNIQUE PROJECT** that answers: Where to invest, What to buy, and How to sell in Melbourne.

### 📊 4 Interactive Dashboards

#### 1. Regional & Category Trends
- Sales trends across different Regions
- Property Category performance
- Market demand analysis
- Top-performing areas

#### 2. Suburb & Location Performance
- Suburb-wise sales and price distribution
- Impact of Distance from CBD on property value
- Premium hotspot identification

#### 3. Seller & Method Performance
- Seller performance comparison
- Selling Method analysis (Auction, Private Sale, etc.)
- Which strategy closes best deals

#### 4. Property Feature & Insights
- Impact of Rooms, Land Size, Property Age
- Parking, Bathroom, Bedroom analysis
- What buyers actually pay premium for

### 🛠️ Tech Stack
- **Power BI** - Dashboard & Visualization
- **Python** - Data Cleaning & EDA
- **Excel** - Data Preprocessing
- **DAX** - KPIs and Measures

### 📁 Dataset
Melbourne City Property Sales Dataset - Includes attributes like Suburb, Price, Rooms, Distance, Landsize, Seller, Method, Region, Property Type, etc.

### 🔍 Key Insights
- Distance from CBD inversely affects price in most premium suburbs
- Auction method yields higher average price than Private Sale
- Eastern Metropolitan region shows highest sales volume
- Land Size and Room count are top price drivers
